# Granular_Data_Dash

A simple static front page linking to two HTML dashboards.

## Edit before sharing

Open `index.html` and replace the bracketed placeholders for:

- Page title
- One-paragraph explanation
- Contact information
- “More information” link text

Edit `more-information.html`, or replace its link in `index.html` with another URL.

## Put it on GitHub

Upload the **contents of this package** to the root of the `Granular_Data_Dash` repository. Keep the `dashboards/` folder beside `index.html` so the links continue to work.

For GitHub Pages, select the repository’s Pages settings and serve from the branch and folder containing `index.html`.

The `noindex` tags discourage search indexing but do not provide access control. Choose repository and hosting visibility settings appropriate for the material.
